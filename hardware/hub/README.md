# AgriNode HUB-1 — هاب/گیت‌وی واحد (rev A)

یک PCB **دو لایه** (با قوانین درشت برای ساخت کم‌دقت) برای همه‌ی انواع هاب. نوع هاب فقط با قطعاتی که
لحیم می‌کنید تعیین می‌شود. چرا دو لایه؟ نتیجه‌ی آزمایش تک‌لایه در
[`docs/02-architecture.md`](../../docs/02-architecture.md#۵-چرا-hub-1-دو-لایه-شد) آمده است.
معماری کلی: [`docs/02-architecture.md`](../../docs/02-architecture.md)

## انواع (Variant) و قطعات اختیاری

| نوع | کاربرد | بلوک‌هایی که لحیم می‌شوند | BOM |
|---|---|---|---|
| **HUB-W** | نودها ← Wi-Fi ← هاب ← Wi-Fi مودم | فقط هسته | `outputs/bom_HUB-W.csv` |
| **HUB-L** | هاب با ارسال LoRa به نقطه‌ی دور | هسته + `LORA` | `outputs/bom_HUB-L.csv` |
| **HUB-C** | هاب با سیم‌کارت (GPRS، پیامک، تماس هشدار) | هسته + `CELL` | `outputs/bom_HUB-C.csv` |
| **GW-LAN** | گیرنده‌ی LoRa در ساختمان + کابل شبکه به مودم | هسته + `LORA` + `ETH` | `outputs/bom_GW-LAN.csv` |

اختیاری روی همه: `BUZ` (بازر آلارم). هدر I²C برای ماژول اختیاری OLED / RTC / سنسور همیشه روی برد است.
ستون `Option` در `outputs/bom.csv` نشان می‌دهد هر قطعه متعلق به کدام بلوک است؛ قطعاتی که ستون Option
ندارند (هسته) همیشه لحیم می‌شوند.

## بلوک‌ها

| بلوک | قطعه‌ی اصلی | توضیح |
|---|---|---|
| پردازنده | ESP32-WROOM-32E (8 یا 16MB) | Wi-Fi + BLE؛ ارتباط با نودها با ESP-NOW یا Wi-Fi |
| ورودی تغذیه | جک 5.5/2.1 + ترمینال 12V، ترمینال پنل خورشیدی 6..24V، USB-B | هر ورودی: فیوز PTC، دیود حفاظت معکوس، TVS |
| مبدل 5V | LM2596S-5 (ورودی 7..40V) | |
| شارژر | TP4056 (1A) + NTC دمای باتری | شارژ فقط بین 0 تا 45 درجه؛ بدون NTC، جامپر `JP_NTC` را لحیم کنید |
| باتری | 18650 **دارای مدار حفاظت** در جاباتری THT | PTC + ماسفت حفاظت از جاگذاری برعکس |
| مسیر توان | دیود + ماسفت AO3401 | با وجود برق از 5V، در قطع برق بدون وقفه از باتری |
| 3.3V | MIC29302 (افت ولتاژ کم، 3A) | |
| LoRa (`LORA`) | Ai-Thinker Ra-02 (SX1278, 433MHz) | آنتن با کابل IPEX به SMA روی جعبه |
| Ethernet (`ETH`) | ENC28J60 + جک HR911105A | 10BASE-T (برای گیت‌وی کافی است) |
| سلولار (`CELL`) | SIM800C (2G: GPRS/SMS/تماس) | رگولاتور 4V جدا با کلید خاموش/روشن، سیم‌کارت micro، آنتن SMA لبه‌ی برد |
| وضعیت | 6 عدد LED RGB آدرس‌پذیر PL9823 (5mm، سوراخ‌دار) | با مبدل سطح BSS138 |
| دکمه‌ها | RESET و BOOT/PAIR (6×6 سوراخ‌دار) | + هدر پروگرام 6 پین |

## ساخت برد

- **دو لایه**، ضخامت 1.6mm، مس 35µm؛ حداقل عرض ترک 0.6mm، فاصله 0.5mm، ویا 0.8mm سوراخ / 1.6mm پد
  (اگر برد را خودتان می‌سازید، ویاها را با سیم مسی نازک از دو طرف لحیم کنید).
- همه‌ی قطعات (SMD و سوراخ‌دار) در **سمت رو**؛ SMD فقط 1206، SOT-23، SOT-223، SOIC، TO-263.
- صفحه‌ی زمین (GND pour) در هر دو لایه.
- زیر آنتن ESP32 (لبه‌ی بالای برد) مس و ترک ممنوع است.
- پس از مونتاژ و تست، **کوتینگ محافظ** (Conformal Coating) بزنید؛ کانکتورها، دکمه‌ها و LEDها را ماسک کنید.
- برای آزمایش مجدد نسخه‌ی تک‌لایه: `HUB_LAYERS=1 python3 pcb.py --route`
  (مسیرهای لایه‌ی رو به جامپر سیمی `W1..Wn` تبدیل می‌شوند).
