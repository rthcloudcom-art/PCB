## ۱. معماری ماژولار

### ۱-۱. لایه‌های سیستم

```
 ┌───────────────────────────── سرور / ابر / داشبورد / اپ موبایل ─────────────────────────────┐
                                        ▲  اینترنت (Wi-Fi / LAN / 4G)
 ┌──────────────── لایه‌ی ۱: گیت‌وی (آماده) ── HUB-W / HUB-L / HUB-C / GW-LAN ────────────────┐
                    ▲ Wi-Fi / ESP-NOW                          ▲ LoRa
 ┌──── لایه‌ی ۲: کنترلر ── CTRL ────┐              ┌── لایه‌ی ۴: نودهای بی‌سیم باتری/خورشیدی ──┐
 │ مغز هر سالن/اتاق/گلخانه/استخر    │              │ خاک، هواشناسی، شیر آبیاری، مخزن، کندو…     │
 └──────────────┬──────────────────┘              └────────────────────────────────────────────┘
                │ AgriBus (کابل شبکه‌ی CAT5: دیتای RS-485 + تغذیه‌ی 24V)
 ┌──────────────┴──── لایه‌ی ۳: ماژول‌های توسعه (روی ریل DIN داخل تابلو) ────────────────────┐
 │ رله │ SSR │ ورودی دیجیتال │ ورودی آنالوگ │ خروجی آنالوگ │ موتور │ شیر │ برق سه‌فاز │ … │
 └───────────────────────────────────────────────────────────────────────────────────────────┘
                │ کابل سنسور
 ┌──────────────┴──── لایه‌ی ۵: سنسورها و پروب‌های هوشمند (با شناسه‌ی خودکار) ─────────────┐
```

### ۱-۲. قوانین معماری

- **یک کنترلر برای هر فضای مستقل** (هر سالن، اتاق قارچ، گلخانه یا استخر). خرابی یا قطع یک کنترلر فقط همان فضا را درگیر می‌کند.
- **کنترلر فقط ولتاژ پایین**؛ همه‌ی 220/380 ولت در ماژول‌های تابلو. رله‌ی اختیاری روی خود کنترلر هم پیش‌بینی شده، ولی توصیه، ماژول رله است.
- **هر ماژول یک میکروکنترلر کوچک خودش را دارد** (CH32V003 یا ATtiny، پکیج SOP):
  - در قطع کابل یا خرابی کنترلر، ماژول خودش به **حالت امن** از پیش تعیین‌شده می‌رود.
  - فرمان دستی Auto/Off/On روی ماژول حتی بدون کنترلر کار می‌کند.
- **شناسایی خودکار:** کنترلر هنگام روشن شدن، ماژول‌های روی باس را پیدا می‌کند (نوع، نسخه، سریال، آدرس).
- **پروفایل کاربری در فریم‌ور:** نوع کاربری فقط در تنظیمات انتخاب می‌شود؛ سخت‌افزار یکی است.
- **پایه‌ی نصب یکسان:** همه‌ی ماژول‌ها روی **ریل DIN**، با جعبه و ابعاد یکسان.

## ۲. پیشنهاد اتصالات

| اتصال | پیشنهاد | دلیل |
|---|---|---|
| گیت‌وی ↔ کنترلر | Wi-Fi یا ESP-NOW؛ رزرو: RS-485 سیمی | سیم‌کشی کم؛ مسیر رزرو برای سالن‌های فلزی |
| کنترلر ↔ ماژول‌ها (AgriBus) | کابل CAT5/CAT6 با RJ45، زنجیره‌ای | کابل ارزان؛ دیتا و برق در یک کابل |
| پایه‌های RJ45 | 1-2: RS-485 · 3-6: شناسایی/آدرس‌دهی · 4-5: +24V · 7-8: GND | ماژول‌های کم‌مصرف برق را از کابل می‌گیرند |
| مشخصات باس | RS-485 ایزوله، Modbus RTU، 115200bps، تا 1000 متر، تا ۶۴ ماژول | استاندارد صنعتی |
| آدرس‌دهی | خودکار زنجیره‌ای؛ DIP فقط برای حالت دستی | Plug & Play |
| مقاومت پایان خط | خودکار (آخرین ماژول) | حذف خطای رایج نصب |
| کابل‌های قدرت و سنسور | ترمینال پیچی جداشدنی 5.08mm | تعویض ماژول بدون باز کردن سیم‌ها |
| پروب‌های هوشمند | M12 (حرفه‌ای) یا ترمینال (اقتصادی) | M12 ضدآب IP67 |
| نودهای بی‌سیم | ESP-NOW (~200m) یا LoRa (چند کیلومتر) | بسته به فاصله |
| HMI | نمایشگر لمسی سریال آماده (DWIN / Nextion) | طراحی صفحه بدون برنامه‌نویسی سنگین |

## ۴. سبد محصولات

### ۴-۱. گیت‌وی‌ها (آماده)
HUB-W · HUB-L · HUB-C · GW-LAN. پیشنهاد آینده: HUB-PRO (LAN + 4G + LoRa با سوییچ خودکار).

### ۴-۲. کنترلر جنرال CTRL
- ESP32 + میکروکنترلر ناظر مستقل + واچ‌داگ؛ کنترل کاملاً محلی؛ **مدیریت دستورالعمل (Recipe)** روزبه‌روز.
- FRAM (شمارنده‌ها + جعبه‌سیاه ۱۰۰۰ رویداد)، microSD، RTC، OTA با بازگشت.
- ورودی 24VDC (9–36V)، خورشیدی، UPS لیتیومی، تأمین برق باس.
- روی برد: ۴ رله‌ی اختیاری، ۴ DI ایزوله (۲ شمارنده)، ۴ AI همه‌کاره، ۲ AO، تشخیص ۳ فاز سطح ۱، 1-Wire، I²C تقویت‌شده، ۲ × RS-485 ایزوله، ورودی ترموستات پشتیبان + خروجی آژیر مستقل.
- پورت نمایشگر لمسی، بازر، نوار LED، دکمه‌ی جفت‌سازی + QR، سوییچ درب جعبه، سنسور داخل تابلو.

### ۴-۳. ماژول‌های توسعه‌ی AgriBus

| کد | نام | امکانات کلیدی |
|---|---|---|
| REL-8 | ۸ رله | 16A، سوییچ دستی هر کانال، سنسور جریان، فیدبک کنتاکتور، RC، شمارش ساعت کار، راه‌اندازی پلکانی |
| SSR-4 | ۴ رله‌ی حالت جامد | تا 25A، کنترل توان تدریجی هیتر، سوییچ در صفر ولتاژ |
| DI-16 | ۱۶ ورودی دیجیتال | ایزوله 5–24V، ۴ شمارنده‌ی سریع، تشخیص قطع سیم |
| AI-8 | ۸ ورودی آنالوگ | 0-10V، 4-20mA، PT100/PT1000، NTC، پتانسیومتر؛ 18 بیت |
| AO-4 | ۴ خروجی آنالوگ | ایزوله 0-10V یا 4-20mA با فیدبک |
| MOT-4 | ۴ کانال موتور | DC 24V یا AC 220V، لیمیت، تشخیص گیر، موقعیت درصدی |
| VALVE-8 | ۸ شیر آبیاری | 24VAC یا DC، لچینگ، دبی‌سنج، تشخیص شیر خراب و نشت |
| DOSE-4 | کوددهی | ۴ پمپ دوزینگ، PID روی EC/pH، سطح مخزن، قفل ایمنی |
| WQ-4 | کیفیت آب | pH، ORP، EC، DO ایزوله؛ جبران دمایی؛ کالیبراسیون در اپ |
| SCALE-4 | ۴ ترازو | لودسل 24 بیتی؛ سیلو، پرنده، کندو، خشک‌کن |
| PWR-3P | برق سه‌فاز | ولتاژ، جریان، توان، kWh؛ ترتیب و قطع فاز؛ قطع موتور در خطا |
| GEN | ژنراتور و ATS | استارت خودکار، کاهش بار، پایش ژنراتور |
| GAS-4 | گازسنج | NH₃، CO₂، CO، H₂S، CH₄، O₂، اتیلن |
| ALM | آژیر | آژیر و چراغ گردان، شماره‌گیر، باتری داخلی |

### ۴-۴. پروب‌ها
پروب اقلیم (CLIMA)، سایکرومتر خشک و مرطوب، پروب دمای کمپوست، کابل دمای سیلو؛ همه با شناسایی خودکار.

### ۴-۵. نودهای بی‌سیم
NODE-S (خاک) · NODE-W (هواشناسی) · NODE-V (شیر آبیاری) · NODE-T (مخزن و چاه) · NODE-H (کندو).
