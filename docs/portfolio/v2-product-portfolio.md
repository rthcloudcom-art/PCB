## ۱. اصل «برد کم، گزینه‌ی مونتاژ زیاد»

### ۱-۱. روش کار
- روی هر PCB **جای همه‌ی قطعات همه‌ی مدل‌ها** وجود دارد. هر مدل فقط بلوک‌های خودش را لحیم می‌کند؛ بقیه‌ی جاها خالی می‌ماند.
- **BOM هر مدل خودکار تولید می‌شود**، همان روشی که برای بردهای هاب انجام شد: ستون Option در BOM، و فایل BOM جدا برای هر مدل.
- **شناسه‌ی مونتاژ (Assembly ID):** یک حافظه‌ی کوچک I²C (24C02، SOIC-8) روی هر برد مدل، شماره‌سریال، تاریخ تولید و ضرایب کالیبراسیون را نگه می‌دارد. فریم‌ور یکی است و با خواندن این حافظه می‌فهمد روی برد چه بلوک‌هایی هست.
- **ارتقا در محل:** مثلاً یک CTRL-S بعداً با لحیم قطعات ترازو به CTRL-P تبدیل می‌شود، یا به PWR-8 سنسور جریان اضافه می‌شود.

### ۱-۲. مزایا نسبت به ماژول‌های متعدد
- فقط ۴ طرح برای طراحی، تست، مستندسازی و نگهداری.
- انبار: فقط ۴ نوع PCB خام؛ قطعات مشترک بین بردها.
- قیمت هر PCB با تیراژ بالاتر پایین می‌آید.
- نصب ساده‌تر: کابل‌کشی بین ماژول‌های زیاد حذف می‌شود.

### ۱-۳. هزینه‌ی این روش
- برد مدل پایه همان ابعاد برد مدل حرفه‌ای را دارد؛ هزینه‌ی PCB خام کمی بیشتر است (قطعات گران لحیم نمی‌شوند).
- برای نیازهای خیلی بزرگ (مثلاً ۲۴ رله در مرغداری) از **چند برد PWR یکسان** استفاده می‌شود، نه برد جدید.

## ۲. معماری سیستم

```
          ┌──────────── سرور / داشبورد / اپ موبایل / پیامک و تماس ────────────┐
                                     ▲ اینترنت
          ┌──────── HUB-W / HUB-L / HUB-C / GW-LAN (موجود) ────────┐   (سایت کوچک: CTRL مستقیم به مودم Wi-Fi)
                          ▲ Wi-Fi / ESP-NOW
   ┌──────────────────────┴──────────────────────┐        بی‌سیم (ESP-NOW / LoRa)
   │          CTRL  — مغز هر فضا (ولتاژ پایین)    │◄──────────────── NODE-S / W / V / T / H / C
   │ ورودی آنالوگ/دیجیتال، خروجی آنالوگ/ماسفت،   │
   │ ترازو، کیفیت آب، تاریخچه، دستورالعمل، ایمنی │◄── باس سنسور RS-485 ── PROBE-CL / PS / GS / TM / DP
   └──────────────────────┬──────────────────────┘
                          │ AgriBus: یک کابل شبکه (دیتا + خط ایمنی + برق 24V)
   ┌──────────────────────┴──────────────────────┐
   │ PWR #1 … PWR #16 — تابلو برق (220/380V)      │── فن، پمپ، هیتر، موتور، کنتاکتور، ژنراتور
   └─────────────────────────────────────────────┘
```

### ۲-۱. قوانین معماری
- **یک CTRL برای هر فضای مستقل** (سالن، اتاق قارچ، گلخانه، استخر، سردخانه). خرابی یا قطع یکی فقط همان فضا را درگیر می‌کند.
- **CTRL کاملاً ولتاژ پایین (SELV).** هیچ سیم 220 ولت به آن نمی‌رسد؛ ایمن برای نصب در راهرو یا دفتر، و ساده‌تر برای گرفتن استاندارد.
- **PWR داخل تابلو برق**، کنار کنتاکتورها و فیوزها.
- **هر برد PWR پردازنده‌ی خودش را دارد** و در قطع کابل یا خرابی CTRL، طبق **DIP سوییچ سخت‌افزاری** هر رله به حالت امن می‌رود (بخش ۴-۴).
- **کنترل کاملاً محلی:** همه‌ی منطق کنترل روی CTRL اجرا می‌شود. هاب و اینترنت فقط برای نظارت، هشدار و تنظیم از راه دور هستند.
- **سایت کوچک بدون هاب:** CTRL خودش Wi-Fi دارد و می‌تواند مستقیم به مودم وصل شود.
- **مزرعه‌ی بدون برق:** نودها مستقیم به HUB-L یا GW-LAN وصل می‌شوند؛ CTRL لازم نیست.

### ۲-۲. اتصال بی‌سیم نود ↔ کنترلر (جزئیات)

| موضوع | مشخصات |
|---|---|
| **پروتکل اصلی** | **ESP-NOW** (2.4GHz، بدون نیاز به مودم، رمزنگاری‌شده) |
| **برد تقریبی** | داخل سالن: 30 تا 80 متر · فضای باز با دید مستقیم: 150 تا 250 متر (آنتن داخلی) · با نسخه‌ی آنتن خارجی (ESP32-WROOM-32UE + آنتن SMA): چند صد متر |
| **فاصله‌ی دورتر** | **LoRa 433MHz** (ماژول Ra-02 روی CTRL-P و نود): فضای باز تقریباً 1 تا 5 کیلومتر |
| **تکرارکننده (مش)** | هر نود برقی (مثلاً NODE-C برق‌دار) می‌تواند پیام نودهای دورتر را به CTRL برساند |
| **ظرفیت** | حدود ۲۰ نود مستقیم برای هر CTRL با رمزنگاری؛ بیشتر از طریق تکرارکننده یا LoRa |
| **هم‌زیستی با Wi-Fi** | CTRL هم‌زمان به هاب/مودم (Wi-Fi) و به نودها (ESP-NOW) وصل است؛ هر دو روی یک کانال Wi-Fi کار می‌کنند (کانال مودم باید ثابت باشد) |
| **جفت‌سازی** | فشار دکمه‌ی PAIR روی CTRL و نود، یا اسکن QR نود با اپ |
| **گزارش‌دهی** | دوره‌ای (قابل تنظیم) + **فوری هنگام تغییر مهم** (عبور از آستانه) · تأیید دریافت و ارسال مجدد |
| **قطع ارتباط** | نود داده‌ها را با زمان ذخیره می‌کند (تا چند روز) و بعد از وصل شدن ارسال می‌کند |
| **فرمان به نود** (مثلاً باز کردن شیر) | نود باتری‌خور هر 30 ثانیه تا 5 دقیقه (قابل تنظیم) بیدار می‌شود و فرمان‌های منتظر را می‌گیرد؛ نود برق‌دار بلافاصله |
| **به‌روزرسانی** | فریم‌ور نودها از طریق CTRL به‌صورت بی‌سیم (OTA) |

### ۲-۳. AgriBus (کنترلر ↔ بردهای قدرت)

| موضوع | مشخصات |
|---|---|
| کابل | کابل شبکه‌ی CAT5e/CAT6 با کانکتور RJ45؛ هر برد ۲ سوکت ورودی/خروجی برای اتصال زنجیره‌ای |
| پایه‌ها | 1-2: RS-485 (A/B) · **3-6: خط ایمنی SAFE** · 4-5: +24V · 7-8: GND |
| دیتا | RS-485 ایزوله در سمت CTRL (ADM2587E، 2.5kV) · Modbus RTU · 115200bps · تا 1000 متر |
| **خط ایمنی SAFE** | ناظر سخت‌افزاری CTRL یک سیگنال ضربان (مربعی) روی این زوج می‌فرستد. اگر قطع شود (کابل قطع، CTRL هنگ، برق CTRL قطع)، **بردهای PWR در کمتر از ۱ ثانیه با سخت‌افزار به حالت امن می‌روند**، حتی قبل از اینکه نرم‌افزار متوجه شود |
| برق | PWR-8E منبع تغذیه‌ی 24V دارد و می‌تواند CTRL را از همین کابل تغذیه کند؛ یعنی بین تابلو و CTRL **فقط یک کابل شبکه** کشیده می‌شود |
| ظرفیت | تا ۱۶ برد PWR روی یک CTRL (۱۲۸ رله) |
| آدرس‌دهی | خودکار زنجیره‌ای؛ DIP سوییچ برای حالت دستی |
| مقاومت پایان خط | خودکار روی آخرین برد |

### ۲-۴. باس سنسور (CTRL ↔ پروب‌ها)
- پورت دوم RS-485 روی CTRL، با کابل ۴ رشته (A، B، +12/24V، GND).
- تا ۳۲ پروب زنجیره‌ای روی یک کابل، تا چند صد متر.
- همین پورت برای **دستگاه‌های شخص ثالث با Modbus** هم هست: اینورتر فن و پمپ، کنتور برق، سنسورهای صنعتی خاک و آب، اکسیژن‌سنج صنعتی.

## ۳. برد ۱ — CTRL (کنترلر اصلی)

| ورودی دیجیتال ایزوله (DI) | 4 | 8 | 8 |

### ۳-۲. پردازش و ایمنی
- **ESP32-WROOM-32E** (یا 32UE با آنتن خارجی برای سالن‌های فلزی).
- **ناظر ایمنی مستقل:** میکروکنترلر CH32V003 (SOP-16).
  - واچ‌داگ ESP32؛ اگر ESP32 هنگ کند یا مدام ری‌استارت شود، آن را ریست می‌کند و رویداد را ثبت می‌کند.
  - تولید ضربان خط SAFE برای بردهای PWR.
  - پایش ولتاژها (افت ولتاژ، باتری ضعیف).
- **پردازنده‌ی کمکی ورودی/خروجی:** CH32V003 دوم، برای PWM خروجی‌ها، شمارش پالس و حذف لرزش ورودی‌ها. پایه‌های ESP32 کافی نیستند و بار پردازشی هم پخش می‌شود.
- **گسترش‌دهنده‌ی پایه** MCP23017 (SOIC-28W) برای LEDها و ورودی‌های کم‌سرعت.
- **شناسه‌ی مونتاژ** 24C02: مدل، سریال، کالیبراسیون.

### ۳-۳. حافظه و زمان
- **FRAM ‏FM24V10** (128KB، بدون محدودیت نوشتن):
  - شمارنده‌های پالس (کنتور آب، دبی‌سنج، باران) که **در قطع برق حتی یک پالس هم گم نمی‌کنند**.
  - آخرین وضعیت همه‌ی خروجی‌ها.
  - **جعبه‌سیاه:** بیش از ۱۰۰۰ رویداد آخر با زمان (قطع برق، آلارم، فرمان دستی، خطا، تغییر تنظیمات).
- **کارت SD استاندارد** (سوکت بزرگ؛ microSD با دستگاه شما قابل ساخت نیست): ثبت داده‌ی دقیقه‌ای برای چند ماه.
- **Flash ‏8MB** با دو پارتیشن فریم‌ور: OTA امن با **بازگشت خودکار** اگر نسخه‌ی جدید خراب بود.
- **DS3231M** + باتری CR2032؛ همگام‌سازی با هاب یا اینترنت؛ منطقه‌ی زمانی.

### ۳-۴. تغذیه
- **ورودی‌ها:**
  - 24VDC صنعتی (بازه‌ی 9 تا 36V)، روی ترمینال یا از کابل AgriBus.
  - پنل خورشیدی 6 تا 24V.
  - USB 5V برای تست و پروگرام.
- **حفاظت:** دیود معکوس، TVS، فیوز PTC روی هر ورودی.
- **ریل‌ها:** 5V (LM2596) و 3.3V (MIC29302).
- **UPS:** ۱ یا ۲ باتری 18650 (موازی) با شارژر TP4056 و NTC دمای باتری. CTRL در قطع برق کار می‌کند و هشدار می‌فرستد؛ بسته به بار سنسورها چند ساعت تا حدود یک روز.
- **تغذیه‌ی 24V سنسورها** (CTRL-S/P): با برق، مستقیم از ورودی؛ در قطع برق، **مبدل Boost ‏XL6009** از باتری. سنسورهای 4-20mA در قطع برق هم کار می‌کنند.
- **پایش:** ولتاژ ورودی، ولتاژ باتری، **جریان ریل سنسورها** (تشخیص اتصال کوتاه کابل سنسور).

### ۳-۵. ورودی‌های آنالوگ همه‌کاره (AI)
هر کانال با یک **DIP سوییچ ۴تایی** روی یکی از این حالت‌ها تنظیم می‌شود:

| حالت | کاربرد | هدف دقت (پس از کالیبراسیون) |
|---|---|---|
| 0-10V | سنسورهای صنعتی ولتاژی، PAR | ±0.1٪ |
| 4-20mA (دوسیمه و سه‌سیمه) | فشار، سطح، رطوبت صنعتی، گاز صنعتی | ±0.1٪ · **جریان زیر 3.6mA = قطع سیم؛ بالای 21mA = خطای سنسور** |
| PT100 / PT1000 (۲ و ۳ سیمه) | دمای کمپوست، آب، جوجه‌کشی، سایکرومتر | ±0.2°C (هدف ±0.1°C با PT1000 سه‌سیمه برای جوجه‌کشی) |
| NTC 10k | دمای عمومی ارزان | ±0.3°C |
| پتانسیومتر | **موقعیت واقعی** پنجره، اینلت، دمپر | 0.1٪ |
| کنتاکت خشک | لیمیت‌سوییچ، شناور | — |

- **مبدل:** ۲ × MCP3424 (18 بیت، SOIC-14)، اندازه‌گیری نسبی (Ratiometric) با مقاومت مرجع 0.1٪ برای RTD.
- **حفاظت هر کانال:** PTC سری + TVS + دیود کلمپ. **اتصال اشتباه 24V به هر کانال آسیبی نمی‌زند.**
- **کالیبراسیون** هر کانال در کارخانه، ذخیره در حافظه‌ی خود برد.

### ۳-۶. ورودی‌های دیجیتال ایزوله (DI)
- 5 تا 30VDC، ایزوله با اپتوکوپلر؛ **Sink یا Source** با یک جامپر (سازگار با همه‌ی سنسورهای PNP و NPN صنعتی).
- **۴ کانال شمارنده‌ی سریع** تا 5kHz (اپتوکوپلر سریع 6N137): دبی‌سنج، کنتور آب و گاز، بادسنج، باران‌سنج، شمارنده‌ی تخم‌مرغ.
- اندازه‌گیری **فرکانس و نرخ** (دبی لحظه‌ای، سرعت باد)، علاوه بر شمارش کل.
- LED وضعیت کنار هر ترمینال.

### ۳-۷. خروجی‌های ماسفت 24V (DO)
- 3A برای هر کانال (ماسفت DPAK)، **PWM تا 25kHz**.
- **اندازه‌گیری جریان هر کانال** (شنت): تشخیص **قطع بار** (شیر سوخته، سیم قطع) و **اتصال کوتاه** با قطع خودکار.
- دیود محافظ بار سلفی و فیوز PTC.
- **کاربرد:** شیر برقی DC، پمپ دوزینگ پریستالتیک 24V، دیمر LED ‏24V، فرمان به SSR، آژیر 24V، فن‌های DC.

### ۳-۸. خروجی‌های آنالوگ (AO)
- 0-10V یا 4-20mA برای هر کانال، با جامپر.
- دقت مؤثر 12 بیت (PWM فیلترشده + تقویت‌کننده).
- **بازخوانی خروجی** (تشخیص قطع سیم یا اتصال کوتاه).
- **کاربرد:** اینورتر فن و پمپ، فن‌های EC، دیمر 1-10V نور، شیر تناسبی سرمایش و گرمایش، دمپر هوا، هیتر تناسبی.

### ۳-۹. ترازو (CTRL-P)
- ۲ کانال لودسل 24 بیتی (HX711، SOP-16)، اتصال ۴ یا ۶ سیمه، تحریک 5V.
- فیلتر دیجیتال ضد لرزش؛ **صفر و کالیبراسیون با وزنه از طریق اپ**.
- **کاربرد:** سیلوی دان، هاپر، **ترازوی خودکار پرنده** (میانگین وزن گله)، **خشک‌کن** (تشخیص پایان خشک شدن)، مخزن مایع.

### ۳-۱۰. کیفیت آب ایزوله (CTRL-P)
- **۴ سوکت** برای مدارهای pH، ORP، EC و شوری، اکسیژن محلول (DO)، در قالب استاندارد EZO.
- **هر سوکت ایزولاسیون کامل** دارد: تغذیه‌ی ایزوله‌ی B0505S و ایزولاتور I²C ‏ISO1540. بدون ایزولاسیون، پروب‌هایی که در یک آب هستند روی هم اثر می‌گذارند و اعداد غلط می‌دهند.
- کانکتور BNC برای پروب‌ها، **جبران دمایی خودکار** از سنسور دمای آب.
- **ویزارد کالیبراسیون** ۱، ۲ یا ۳ نقطه‌ای در اپ؛ **یادآوری کالیبراسیون و تعویض پروب** بر اساس عمر.
- جایگزین برای مقیاس بزرگ: پروب‌های صنعتی RS-485 روی باس سنسور.

### ۳-۱۱. ارتباطات
- **AgriBus** (به PWR): RS-485 ایزوله ADM2587E، ۲ × RJ45 + ترمینال، مقاومت پایان خط خودکار، خط SAFE.
- **باس سنسور** (CTRL-S/P): RS-485 با محافظ SM712، تغذیه‌ی 12/24V برای پروب‌ها.
- **1-Wire:** با درایور اختصاصی DS2482 (SOIC-8) برای کابل بلند؛ تا حدود ۲۰ سنسور DS18B20 و تا حدود 50 متر.
- **I²C خارجی:** تقویت‌شده با P82B715؛ کابل تا 20 تا 30 متر.
- **بی‌سیم:** Wi-Fi (هاب یا مودم)، ESP-NOW (هماهنگ‌کننده‌ی نودها)، LoRa اختیاری (Ra-02، کانکتور IPEX → SMA).
- **USB-B:** پروگرام (CH340C با ریست خودکار) و کنسول عیب‌یابی.

### ۳-۱۲. رابط کاربری
- **پورت HMI** برای نمایشگر لمسی DWIN یا Nextion (4.3 تا 7 اینچ) روی درب تابلو.
- هدر نوار LED ‏WS2813، بازر، دکمه‌های RESET و BOOT/PAIR.
- LED برای هر ورودی و خروجی، QR کد روی برد برای راه‌اندازی با موبایل.
- **ورودی سوییچ درب تابلو** (هشدار باز شدن) و **سنسور دما و رطوبت داخل تابلو** (هشدار نفوذ آب یا گرمای بیش از حد).

### ۳-۱۳. ساخت و نصب
- ۲ لایه با قوانین ساخت درشت (ترک 0.5mm، فاصله 0.5mm)؛ فقط SOIC، SOT-23، 1206، DPAK و قطعات سوراخ‌دار.
- **ترمینال‌های پیچی جداشدنی** 5.08mm، گروه‌بندی و **رنگ‌بندی** (ورودی، خروجی، تغذیه، ارتباط) با برچسب روی سیلک.
- جعبه‌ی ریل DIN یا جعبه‌ی دیواری IP65 با پنجره برای LEDها و HMI.

## ۴. برد ۲ — PWR (برد قدرت)

### ۴-۱. مدل‌ها

| بلوک | PWR-4 | PWR-8 | PWR-8E |
|---|:---:|:---:|:---:|
| رله‌ی 16A با سوییچ دستی و DIP حالت امن | 4 | 8 | 8 |
| سنسور جریان هر رله | — | 4 کانال | 8 کانال |
| جفت‌رله‌ی موتور چپ‌گرد/راست‌گرد | 1 جفت | 2 جفت | 2 جفت |
| SSR/تریاک 16A (کنترل تناسبی هیتر) | — | 2 | 2 |
| ورودی‌های ایزوله‌ی 230VAC (فاز و وضعیت) | 3 | 7 | 7 |
| تشخیص برق سطح ۱ (حضور فاز) | ✅ | ✅ | ✅ |
| تشخیص برق سطح ۲ (کیفیت برق) | — | اختیاری | ✅ |
| تشخیص برق سطح ۳ (کنتور انرژی، ۴ کلمپ جریان) | — | — | ✅ |
| ترموستات سخت‌افزاری پشتیبان + آژیر | ✅ | ✅ | ✅ |
| منبع تغذیه‌ی 24V داخلی (تغذیه‌ی CTRL از کابل) | — | اختیاری | ✅ |

### ۴-۲. پردازنده و ارتباط
- میکروکنترلر محلی **PY32F003** (SOP-16، مبدل آنالوگ 12 بیتی برای اندازه‌گیری برق).
- AgriBus: RS-485 با محافظ، ۲ × RJ45 برای اتصال زنجیره‌ای، گیرنده‌ی ایزوله‌ی خط SAFE.
- شناسه‌ی مونتاژ و کالیبراسیون.

### ۴-۳. رله‌ها
- 16A/250VAC، سوراخ‌دار (مثلاً HF115F)؛ رله‌ی ۱ تا ۴ دوطرفه (NO/NC/COM)، رله‌ی ۵ تا ۸ فقط NO.
- درایور ULN2803 (SOIC-18W)، LED وضعیت برای هر رله.
- **حفاظت کنتاکت** (RC اسنابر یا واریستور) اختیاری برای هر رله: عمر بیشتر رله و نویز کمتر هنگام قطع بار سلفی.
- **شمارش ساعت کار و تعداد قطع و وصل** هر رله: هشدار «رله نزدیک پایان عمر مکانیکی است» یا «زمان سرویس فن».

### ۴-۴. کنترل دستی و حالت امن (سخت‌افزاری)
- **سوییچ سه‌حالته Auto/Off/On برای هر رله.**
  - Hand مستقیماً سیم‌پیچ رله را روشن می‌کند و Off آن را قطع؛ **مستقل از پردازنده**.
  - وضعیت سوییچ خوانده می‌شود و **در اپ نمایش داده می‌شود** که کدام کانال دستی است، تا کسی سوییچ را فراموش نکند.
- **DIP سوییچ حالت امن برای هر رله:** وقتی خط SAFE قطع شود یا پردازنده‌ی PWR از کار بیفتد، هر رله به حالتی می‌رود که DIP تعیین کرده (روشن یا خاموش). مثال مرغداری: فن‌ها روشن، بخاری خاموش. این منطق با **گیت‌های سخت‌افزاری** (74HC) پیاده می‌شود، نه با نرم‌افزار.

### ۴-۵. سنسور جریان هر کانال
- ACS712 (SOIC-8، ایزولاسیون داخلی) روی هر رله، اختیاری.
- **تشخیص:** بار سوخته یا قطع (فن کار نمی‌کند)، **خشک‌کار پمپ** (جریان کم)، **اضافه‌بار یا گیر موتور** (جریان زیاد).
- **امضای جریان:** سیستم الگوی عادی هر بار را یاد می‌گیرد؛ انحراف تدریجی (بلبرینگ خراب، تسمه‌ی شل، فیلتر گرفته) قبل از خرابی کامل هشدار داده می‌شود.
- تخمین انرژی مصرفی هر بار، به‌همراه ولتاژ سطح ۲.

### ۴-۶. موتورهای چپ‌گرد/راست‌گرد
- رله‌های ۵-۶ و ۷-۸ با جامپر لحیمی به **جفت معکوس‌کننده** تبدیل می‌شوند. **قفل متقابل سخت‌افزاری** (زنجیره‌ی کنتاکت NC) + قفل نرم‌افزاری + مکث 0.5 ثانیه بین تغییر جهت.
- **کاربرد:** موتور پنجره‌ی سقفی و کناری، پرده‌ی سایه‌بان و حرارتی، اینلت مرغداری، دمپر، کرکره.
- لیمیت‌سوییچ‌ها و پتانسیومتر موقعیت روی ورودی‌های CTRL؛ **تشخیص گیر کردن** از سنسور جریان.
- **موقعیت درصدی** (بر اساس زمان حرکت یا پتانسیومتر) و **کالیبراسیون خودکار** مسیر با یک بار رفت و برگشت کامل.

### ۴-۷. SSR/تریاک (PWR-8/8E)
- ۲ کانال 16A (تریاک BT139 با هیت‌سینک + اپتوتریاک MOC3063 با سوییچ در صفر ولتاژ + اسنابر).
- **کنترل توان تناسبی** هیتر برقی 0 تا 100٪: بدون صدا، بدون استهلاک، **دمای بسیار پایدار** (جوجه‌کشی، خشک‌کن، اتاق قارچ).
- جایگزین: فرمان شیرهای آبیاری 24VAC.

### ۴-۸. ورودی‌های ایزوله‌ی 230VAC
- **۳ ورودی فاز (L1، L2، L3):** تشخیص سطح ۱. برای تک‌فاز فقط L1 وصل و در تنظیمات «تک‌فاز» انتخاب می‌شود.
- **۴ ورودی وضعیت:** کنتاکت کمکی کنتاکتور (**تأیید اینکه کنتاکتور واقعاً وصل شده**)، رله‌ی حرارتی موتور (قطع اضافه‌بار)، ژنراتور در حال کار، وضعیت ATS.

### ۴-۹. تشخیص برق — سه سطح روی یک برد

| سطح | امکانات | قطعات اضافه | هزینه‌ی تقریبی قطعات (دلار، عمده) |
|---|---|---|---|
| **۱** (همه‌ی مدل‌ها) | قطع و وصل هر فاز | اپتوکوپلر | ~1$ |
| **۲** (PWR-8 اختیاری، 8E) | + ولتاژ واقعی هر فاز، فرکانس، **ترتیب فاز**، **قطع یک فاز**، **عدم تعادل**، افت و افزایش ولتاژ با ثبت زمان | ۳ × ترانس ولتاژ ZMPT101B | ~5 تا 7$ |
| **۳** (8E) | + جریان، توان اکتیو و راکتیو، ضریب توان، **کیلووات‌ساعت هر فاز**، دیماند، **هزینه‌ی برق** | + ۴ کلمپ جریان SCT-013 (تا 100A) | ~18 تا 25$ |

- **در خطای فاز** (قطع یک فاز، ترتیب غلط، ولتاژ خارج از محدوده)، موتورهای سه‌فاز تعیین‌شده **ظرف حدود 100 میلی‌ثانیه قطع** می‌شوند و بعد از پایدار شدن برق به‌صورت خودکار وصل می‌شوند.
- دقت هدف سطح ۳: حدود ۱ تا ۲ درصد پس از کالیبراسیون.

### ۴-۱۰. ژنراتور و راه‌اندازی مجدد
- **ژنراتور و ATS:** هر رله قابل تخصیص به استارت و استاپ ژنراتور و فرمان ATS است.
  - **کاهش بار (Load Shedding):** بارهای غیرضروری روی ژنراتور روشن نمی‌شوند.
  - **روشن‌کردن آزمایشی هفتگی ژنراتور**، زمان‌بندی‌شده، با گزارش.
- **راه‌اندازی پلکانی بعد از برگشت برق:** بعد از X ثانیه، بارها به ترتیب اولویت و با فاصله‌ی Y ثانیه روشن می‌شوند تا جریان هجومی فیوز اصلی یا ژنراتور را نیندازد.

### ۴-۱۱. ترموستات سخت‌افزاری پشتیبان (مستقل از هر دو پردازنده)
- ورودی سنسور دمای NTC جداگانه + مقایسه‌گر LM393 + پتانسیومتر تنظیم دمای خطر + هیسترزیس.
- **دمای بالا:** رله‌هایی که با DIP مشخص شده‌اند (مثلاً فن‌ها) روشن، هیترها خاموش، رله‌ی آژیر روشن.
- **دمای پایین** (اختیاری): برای خرابی گرمایش در زمستان (جوجه‌کشی، جوجه‌ی یک‌روزه، گلخانه).
- **حتی اگر CTRL و پردازنده‌ی PWR هر دو از کار افتاده باشند، کار می‌کند.**

### ۴-۱۲. منبع تغذیه‌ی داخلی (PWR-8E، اختیاری در PWR-8)
- ماژول 24V/20W سوراخ‌دار (مثلاً Mean Well IRM-20-24) + فیوز + واریستور + محدودکننده‌ی جریان هجومی.
- تغذیه‌ی خود PWR، **CTRL (از کابل AgriBus)** و سنسورها. سیستم فقط با برق شبکه کار می‌کند و UPS روی CTRL قطعی‌ها را پوشش می‌دهد.

### ۴-۱۳. ساخت (نکات صنعتی)
- **جداسازی ولتاژ بالا:** شیار ایزولاسیون در PCB، فاصله‌ی خزشی حداقل 8 میلی‌متر بین بخش 220V و بخش ولتاژ پایین (ایزولاسیون تقویت‌شده).
- **مسیرهای جریان بالا:** ترک پهن + تقویت با قلع یا سیم مسی (مس 35 میکرون برای 16A به‌تنهایی کافی نیست).
- ترمینال‌های قدرت 7.62mm با رده‌ی 16A.
- واریستور روی ورودی‌های برق، خازن‌های X2 رده‌ی ایمنی، جافیوزی.

### ۵-۲. پردازش و رادیو
- ESP32-WROOM-32E یا 32UE (آنتن خارجی، برای فاصله‌ی بیشتر).
- ESP-NOW به CTRL (یا هاب)؛ LoRa Ra-02 اختیاری.
- **شمارش پالس در خواب عمیق** با پردازنده‌ی کم‌مصرف داخلی ESP32 (ULP): بادسنج، باران‌سنج و دبی‌سنج بدون بیدار کردن پردازنده‌ی اصلی شمرده می‌شوند و باتری عمر زیادی دارد.

### ۵-۳. تغذیه و عمر باتری
- ۱ یا ۲ باتری 18650؛ شارژر خورشیدی CN3065 (SOP-8) برای پنل 6V؛ ورودی آداپتور 5 تا 24V (اختیاری).
- **جریان خواب هدف: کمتر از 50 میکروآمپر** برای کل برد (رگولاتور کم‌مصرف، قطع برق سنسورها با ماسفت در خواب).
- تغذیه‌ی 12V سنسورهای صنعتی با مبدل Boost، فقط هنگام اندازه‌گیری روشن.
- اندازه‌گیری ولتاژ باتری و **تخمین عمر باقی‌مانده**؛ هشدار باتری ضعیف چند هفته زودتر.

| مدل | گزارش هر ۱۵ دقیقه، بدون پنل (تقریبی) | با پنل 2 تا 5 وات |
|---|---|---|
| NODE-S / NODE-H | حدود ۱ تا ۲ سال | نامحدود |
| NODE-W | حدود ۶ ماه تا ۱ سال | نامحدود |
| NODE-V | بسته به تعداد باز و بسته شدن شیر | نامحدود |

(اعداد تخمینی‌اند و پس از ساخت نمونه اندازه‌گیری می‌شوند.)

### ۵-۴. خروجی‌ها
- **۴ درایور H-bridge** (DRV8871، HSOP-8) برای **شیرهای لچینگ** 9 تا 12V: فقط یک پالس کوتاه مصرف دارند، مناسب نود باتری‌خور.
- ۱ خروجی ماسفت برای فرمان رله یا کنتاکتور پمپ (NODE-T).
- **ایمنی شیر:** اگر ارتباط با CTRL قطع شود، آبیاری بعد از حداکثر زمان تنظیم‌شده خودکار قطع می‌شود؛ هیچ شیری باز نمی‌ماند.

### ۵-۵. هوشمندی روی نود
- **گزارش تطبیقی:** وقتی مقادیر ثابت است کمتر، وقتی سریع تغییر می‌کند بیشتر گزارش می‌دهد.
- **هشدار محلی فوری** (سرمازدگی، سرریز مخزن، سرقت کندو) بدون انتظار برای دوره‌ی بعدی.
- NODE-W: محاسبه‌ی **ET₀** (تبخیر-تعرق) و **نقطه‌ی شبنم** روی خود نود.
- ذخیره‌ی داده‌ها در قطع ارتباط، OTA بی‌سیم، تنظیم از راه دور.

### ۵-۶. جعبه
IP67 با گلند کابل؛ پایه‌ی پنل خورشیدی؛ **محافظ تشعشع** برای سنسورهای هوا (NODE-W).

## ۶. برد ۴ — PROBE (پروب سنسور هوشمند سیمی)

### ۶-۱. چرا پروب هوشمند؟
- سنسورهای دیجیتال معمولی (I²C) فقط تا چند متر کابل کار می‌کنند؛ پروب RS-485 **تا چند صد متر**.
- **ده‌ها پروب روی یک کابل** (زنجیره‌ای)، به‌جای یک کابل برای هر سنسور.
- عدد دیجیتال و کالیبره‌شده در خود پروب؛ نویز کابل روی دقت اثر ندارد.
- با Modbus استاندارد، **به هر PLC یا اسکادای دیگری هم وصل می‌شود**، پس محصول مستقل قابل فروش است.

### ۶-۲. سخت‌افزار مشترک
- میکروکنترلر CH32V003 (SOP-16)؛ RS-485 (SP3485 + SM712)، Modbus RTU.
- تغذیه‌ی 9 تا 30V از کابل.
- **سنسورها به‌صورت ماژول آماده روی هدر** نصب می‌شوند (همان روش ماژول 4G در HUB-C)، چون خود تراشه‌های سنسور با دستگاه شما قابل لحیم نیستند.
- **آدرس و شناسه‌ی خودکار**؛ ضرایب کالیبراسیون در خود پروب؛ تعویض پروب بدون تنظیم دوباره.
- کانکتور M12 (حرفه‌ای) یا ترمینال (اقتصادی).

### ۶-۳. مدل‌ها

| مدل | سنسورها | کاربرد | ویژگی ویژه |
|---|---|---|---|
| **PROBE-CL** (اقلیم) | دما و رطوبت، CO₂ ‏NDIR (مثل SenseAir S8)، نور، فن تهویه‌ی داخلی | گلخانه، مرغداری، قارچ، سردخانه | **فن تهویه‌ی پروب** برای اندازه‌گیری دقیق؛ **گرم‌کن ضدمیعان** برای رطوبت بالا |
| **PROBE-PS** (سایکرومتر) | ۲ × PT1000 (دمای خشک و مرطوب) + مخزن آب فتیله | **قارچ**، مه‌پاشی، رطوبت بالای ۹۰٪ | در رطوبت بالا که سنسورهای معمولی خراب می‌شوند، **روش استاندارد صنعت قارچ** است |
| **PROBE-GS** (گاز) | تا ۲ ماژول الکتروشیمیایی (NH₃، CO، H₂S، O₂، **اتیلن**) + CO₂ اختیاری | مرغداری، دامداری، **سردخانه‌ی میوه**، تونل کمپوست | ثبت تاریخ کالیبراسیون و **عمر سنسور** |
| **PROBE-TM** (دمای چندنقطه‌ای) | تا ۸ × DS18B20 یا ۴ × PT1000 | **میله‌های دمای کمپوست**، **کابل دمای سیلو**، دمای آب در چند عمق | تشخیص نقطه‌ی داغ (خودسوزی سیلو) |
| **PROBE-DP** (فشار) | سنسور اختلاف فشار | **فشار استاتیک سالن مرغداری**، فیلتر هواساز، کانال هوا | تشخیص گرفتگی فیلتر |

## ۷. صنایع هدف و بسته‌های راهکار

در هر بسته، تعداد بردها برای یک واحد نمونه آمده است.

### ۷-۱. گلخانه (شامل تشخیص برق سه‌فاز)
**بردها:** HUB + CTRL-S (یا P برای کوددهی) + ۲ × PWR-8E/8 + NODE-W (هواشناسی بیرون) + ۳ تا ۶ PROBE-CL یا NODE-C

| ورودی/خروجی | تخصیص |
|---|---|
| رله‌ها (PWR) | فن‌ها ۱ تا ۴ مرحله، پمپ پد، مه‌پاش، هیتر، نور رشد، پمپ آبیاری، تزریق CO₂، آژیر |
| جفت‌رله‌ی موتور | پنجره‌ی سقفی، پنجره‌ی کناری، پرده‌ی سایه‌بان، پرده‌ی حرارتی |
| AO | اینورتر فن، دیمر نور رشد، شیر تناسبی گرمایش |
| DO | شیرهای برقی زون‌ها، پمپ‌های دوزینگ کود و اسید |
| AI | فشار آب، سطح مخزن، PAR، پتانسیومتر پنجره‌ها |
| DI | دبی‌سنج (پالس)، باران، لیمیت‌ها، درب |
| کیفیت آب (CTRL-P) | EC و pH محلول غذایی، دمای محلول |

**هوشمندی:** کنترل اقلیم چندمرحله‌ای (تهویه ← پد و فن ← مه‌پاش)؛ **VPD** و **DLI**؛ آبیاری بر اساس تابش تجمعی و رطوبت بستر؛ کوددهی PID روی EC و pH؛ **بستن اضطراری پنجره‌ها** در باد و باران؛ پیش‌بینی بیماری از ساعات خیسی برگ؛ حفاظت سه‌فاز موتورها.

### ۷-۲. هیدروپونیک و کشت عمودی
**بردها:** CTRL-P + PWR-8 + PROBE-CL
**امکانات:** EC، pH، DO و دمای محلول؛ دوزینگ خودکار کود، اسید و باز با قفل ایمنی (بدون جریان آب دوز نکن)؛ دیمر LED و برنامه‌ی نوری؛ پمپ گردش و هواده محلول با سنسور جریان؛ هشدار سرریز یا خالی شدن مخزن.

### ۷-۳. صنعت قارچ (دکمه‌ای، صدفی، شیتاکه)
**بردها برای هر اتاق:** CTRL-S (یا P با ترازوی برداشت) + PWR-8 + PROBE-PS + PROBE-CL + ۲ × PROBE-TM (کمپوست). یک PWR-8E برای کل ساختمان.

**فازهای کنترل (قارچ دکمه‌ای)**

| فاز | دمای کمپوست | دمای هوا | رطوبت | CO₂ | کنترل‌ها |
|---|---|---|---|---|---|
| **تونل پاستوریزه** (فاز ۲) | پاستوریزه 56 تا 60°C (۶ تا ۸ ساعت) → آماده‌سازی 45 تا 48°C تا NH₃ زیر 10ppm | — | — | — | اینورتر فن تونل، دمپر هوای تازه، **O₂ و NH₃ تونل**، برنامه‌ی زمانی |
| **رشد میسلیوم** (فاز ۳ / اسپان‌ران) | 24 تا 26°C | 22 تا 24°C | 90 تا 95٪ | بالا (تا 5000ppm مجاز) | گردش هوا، حداقل هوای تازه |
| **کیسینگ‌ران** | 24 تا 25°C | 22 تا 24°C | 90 تا 95٪ | بالا | مشابه |
| **القای کلاهک** (پینینگ) | 18 تا 20°C | **افت تدریجی** به 16 تا 18°C | 90 تا 95٪ | **کاهش** به زیر 1200ppm | هوای تازه‌ی زیاد، تبخیر کنترل‌شده |
| **برداشت** (۲ تا ۳ فلاش) | 18 تا 20°C | 16 تا 18°C | 85 تا 92٪ | 800 تا 1500ppm | آبیاری بستر بین فلاش‌ها، کنترل تبخیر |

| ورودی/خروجی (هر اتاق) | تخصیص |
|---|---|
| AO | دمپر هوای تازه، اینورتر فن هواساز، شیر ۳راهه‌ی سرمایش، شیر گرمایش |
| رله‌ها | بخارساز یا مه‌پاش، روشنایی، پمپ آبیاری بستر، هیتر برقی (یا SSR تناسبی)، آژیر |
| پروب‌ها | سایکرومتر (رطوبت)، CO₂ و دما، ۴ تا ۸ نقطه‌ی دمای کمپوست |
| DI | درب اتاق (توقف هشدار CO₂ و ثبت ورود)، سوییچ جریان هوا، فشار فیلتر |

**هوشمندی ویژه‌ی قارچ:**
- **دستورالعمل روزبه‌روز برای هر اتاق** با تغییر تدریجی مقادیر؛ اپراتور فقط شروع فاز را اعلام می‌کند.
- **کنترل بر اساس دمای کمپوست:** دمای هوا به‌صورت خودکار تنظیم می‌شود تا کمپوست در دمای هدف بماند.
- **کنترل تبخیر** (اختلاف دما و رطوبت و سرعت هوا روی بستر)، کلید کیفیت کلاهک و وزن محصول.
- **ثبت کامل هر دوره:** کمپوست، فازها، هر فلاش، وزن برداشت؛ **مقایسه‌ی بازدهی اتاق‌ها و دوره‌ها** (کیلوگرم در تن کمپوست).
- **هشدار ایمنی CO₂ برای کارگران** هنگام ورود به اتاق.

### ۷-۴. مرغداری گوشتی و تخم‌گذار
**بردها:** HUB-C + CTRL-P + ۳ × PWR-8/8E + ۲ × PROBE-GS + PROBE-DP + ۴ تا ۸ × NODE-C یا PROBE-CL

| ورودی/خروجی | تخصیص |
|---|---|
| رله‌ها (۱۶ تا ۲۴) | فن‌های تونلی ۸ تا ۱۲ مرحله، فن‌های جانبی، بخاری‌ها ۲ تا ۴، پمپ پد، موتور دان‌خوری و زنجیر، دان‌رسان سیلو، روشنایی، مدیکاتور، آژیر، ژنراتور |
| جفت‌رله‌ی موتور | اینلت‌ها، پرده‌های تونل |
| AO | اینورتر فن، دیمر روشنایی (طلوع و غروب) |
| ترازو | سیلو یا هاپر دان، **ترازوی پرنده** |
| DI (پالس) | کنتور آب، **شمارنده‌ی تخم‌مرغ** (تخم‌گذار) |
| پروب‌ها | NH₃، CO، CO₂، فشار استاتیک، دما و رطوبت چندنقطه‌ای |

**هوشمندی:** منحنی دمای هدف بر اساس سن گله؛ تهویه‌ی حداقلی با تایمر؛ تهویه‌ی تونلی بر اساس دمای مؤثر (با اثر سرعت باد)؛ **FCR** (ضریب تبدیل خوراک)؛ **هشدار افت مصرف آب** (اولین علامت بیماری)؛ برنامه‌ی نوری؛ **تولید روزانه‌ی تخم‌مرغ** (تخم‌گذار)؛ ترموستات پشتیبان سخت‌افزاری و آژیر مستقل؛ ژنراتور خودکار؛ هشدار تماس صوتی.

### ۷-۵. جوجه‌کشی (هچری و ستر)
**بردها:** CTRL-S + PWR-8 (SSR برای هیتر) + PROBE-PS یا PROBE-CL + PROBE-GS (CO₂)
**امکانات:** دمای **±0.1 تا ±0.2°C** با PT1000 سه‌سیمه و هیتر تناسبی SSR؛ رطوبت با سایکرومتر؛ **موتور چرخاندن تخم‌ها** (زمان‌بندی + لیمیت)؛ CO₂ و دمپر؛ برنامه‌ی ۲۱ روزه (ستر → هچر)؛ ترموستات پشتیبان **دوطرفه** (دمای بالا و پایین)؛ هشدار فوری.

### ۷-۶. دامداری و گاوداری شیری
**بردها:** CTRL-P + PWR-8 + PROBE-GS + NODE-C
**امکانات:** **THI** (شاخص تنش حرارتی) و کنترل خودکار فن و مه‌پاش؛ NH₃ و H₂S؛ **دمای مخزن شیر** و حفاظت کمپرسور (جریان)؛ پایش **شست‌وشوی مخزن (CIP)** از دما و زمان؛ سطح آبشخورها؛ باسکول دام (لودسل)؛ دریافت گردنبند یا پدومتر BLE (فعالیت، فحلی) با خود ESP32؛ پورت خواننده‌ی RFID.

### ۷-۷. آبزی‌پروری (ماهی و میگو)
**بردها:** HUB-C + CTRL-P (کیفیت آب) + PWR-8E + در صورت نیاز پروب‌های صنعتی DO روی باس سنسور
**امکانات:**
- DO، pH، ORP، EC و شوری، دمای آب در چند عمق.
- **سنسور جریان روی همه‌ی هواده‌ها** (هواده‌ی سوخته در چند ثانیه تشخیص داده می‌شود).
- **روشن‌کردن پلکانی هواده‌های پشتیبان** با افت اکسیژن.
- **پیش‌بینی افت اکسیژن شبانه** از روند عصر (هشدار قبل از بحران).
- قطع خودکار غذادهی در اکسیژن پایین یا دمای نامناسب.
- ژنراتور خودکار؛ پمپ تعویض آب؛ UV.

### ۷-۸. مزرعه‌ی باز
**بردها:** HUB-L یا GW-LAN + NODE-S (هر زون) + NODE-W + NODE-V + NODE-T؛ در پمپ‌خانه‌ی برق‌دار: CTRL-S + PWR-8E
**امکانات:** آبیاری زونی بر اساس **رطوبت خاک و ET₀**؛ شیرهای لچینگ بی‌سیم؛ **تشخیص نشت** (دبی بدون فرمان آبیاری)؛ NPK و EC خاک؛ گزارش مصرف آب هر زون.

### ۷-۹. باغ
**همه‌ی موارد مزرعه، به‌علاوه:**
- **هشدار و مقابله با سرمازدگی:** دمای نزدیک زمین و نقطه‌ی شبنم؛ روشن‌کردن خودکار آب‌پاش ضدیخ، ماشین باد یا بخاری.
- **پیش‌بینی آفات و بیماری** از ساعات خیسی برگ و دما (درجه-روز).
- NODE-H برای باغ‌هایی که کندو دارند.

### ۷-۱۰. چاه و ایستگاه پمپاژ
**بردها:** HUB-C + CTRL-S + PWR-8E
**امکانات:** استارت و استاپ از راه دور (اپ، **پیامک**)؛ **حفاظت خشک‌کار** (جریان پمپ)؛ حفاظت فاز (قطع فاز، ترتیب فاز، ولتاژ)؛ سطح آب چاه (سنسور فشاری 4-20mA)؛ فشار و دبی خط؛ **کیلووات‌ساعت و هزینه‌ی برق**؛ برنامه‌ی زمانی؛ **حداکثر ساعت کار مجاز** روزانه یا ماهانه (سهمیه‌ی آب)؛ ثبت ساعت کار پمپ.

### ۷-۱۱. سردخانه و انبار میوه (شامل اتمسفر کنترل‌شده)
**بردها:** CTRL-S + PWR-8E + PROBE-CL + PROBE-GS (اتیلن، CO₂، O₂)
**امکانات:** دما و رطوبت؛ **دیفراست** زمانی یا بر اساس نیاز؛ حفاظت کمپرسور (جریان، تأخیر استارت مجدد، فشار)؛ **اتیلن** (هشدار رسیدگی زودرس میوه)؛ کنترل O₂ و CO₂ (اتمسفر کنترل‌شده: ژنراتور نیتروژن، جاذب CO₂)؛ هشدار درب باز؛ مصرف انرژی.

### ۷-۱۲. خشک‌کن (زعفران، پسته، خرما، سبزی، میوه)
**بردها:** CTRL-P + PWR-8 (SSR) + PROBE-CL
**امکانات:** دمای دقیق با هیتر تناسبی؛ کنترل رطوبت با فن خروجی و هوای تازه (دمپر)؛ **تشخیص پایان خشک شدن از روی کاهش وزن** (ترازو)؛ برنامه‌ی دما برای هر محصول (دستورالعمل)؛ **گزارش هر بچ** (زمان، انرژی، درصد کاهش وزن) برای کیفیت و قیمت‌گذاری.

### ۷-۱۳. سیلو و انبار غلات
**بردها:** CTRL-S + PWR-8 + PROBE-TM (کابل دمای چندنقطه‌ای در هر سیلو) + NODE-T (سطح)
**امکانات:** **تشخیص نقطه‌ی داغ** (شروع فساد یا خودسوزی)؛ روشن‌کردن خودکار فن هوادهی وقتی هوای بیرون مناسب است (دما و رطوبت)؛ سطح سیلو؛ رطوبت هوای انبار.

### ۷-۱۴. زنبورداری
**بردها:** HUB-L + NODE-H (یک نود برای یک یا چند کندو)
**امکانات:** **وزن کندو** (جریان شهد، زمان برداشت عسل)؛ دما و رطوبت داخل کندو؛ **تشخیص بچه‌دهی** از افت ناگهانی وزن؛ **هشدار سرقت** (لرزش، کج شدن)؛ مقایسه‌ی کندوها.

### ۷-۱۵. تولید کمپوست و بیوگاز (پیشنهاد)
**بردها:** CTRL-S + PWR-8 + PROBE-TM + PROBE-GS
**امکانات:** دمای توده در چند عمق؛ هوادهی زمان‌بندی‌شده یا بر اساس O₂؛ NH₃ و CH₄؛ ثبت دوره.

## ۸. امکانات نرم‌افزاری مشترک

**کنترل**
- منطق کاملاً محلی روی CTRL: زمان‌بندی، آستانه با هیسترزیس، PID، سناریو (اگر/آنگاه)، **دستورالعمل روزبه‌روز با تغییر تدریجی**.
- **پروفایل صنعت:** با انتخاب «قارچ»، «مرغداری» و...، صفحات، الگوریتم‌ها و پیش‌فرض‌ها آماده است.

**قابلیت اطمینان**
- حالت امن چندلایه (بخش ۹)؛ **سنسور افزونه با رأی‌گیری** برای پارامترهای حیاتی (مثلاً ۳ سنسور دما: اگر یکی با بقیه نخواند کنار گذاشته می‌شود).
- **خودآزمایی دوره‌ای:** سنسورها، رله‌ها، ارتباط، باتری؛ گزارش سلامت.
- **جعبه‌سیاه** رویدادها.

**نگهداری پیشگیرانه**
- ساعت کار و تعداد استارت هر بار؛ **امضای جریان**؛ عمر رله؛ یادآوری سرویس فن، تعویض فیلتر، کالیبراسیون پروب.

**گزارش و تحلیل**
- مصرف برق، آب، دان و کود؛ FCR؛ بازدهی اتاق یا دوره؛ هزینه‌ی انرژی؛ تولید.

**هشدار**
- چندکاناله با **تشدید**: اپ → پیامک → **تماس صوتی** → نفر دوم (اگر نفر اول تأیید نکرد).
- دسته‌بندی شدت (اطلاع / هشدار / بحرانی)؛ **تأخیر و هیسترزیس هشدار** برای جلوگیری از هشدارهای مکرر بی‌مورد.

**دسترسی و یکپارچگی**
- کاربران با سطح دسترسی (مالک، مدیر، کارگر)؛ **ثبت اینکه چه کسی چه فرمانی داد**.
- MQTT، Modbus TCP، Home Assistant، Node-RED؛ اتصال به اسکادای صنعتی.
- راه‌اندازی با موبایل (بلوتوث یا Wi-Fi مستقیم) بدون نیاز به اینترنت.

| لایه | چه کسی | چه زمانی عمل می‌کند |
|---|---|---|
| ۱ | نرم‌افزار CTRL | کنترل عادی، هشدارها، سنسور افزونه |
| ۲ | ناظر سخت‌افزاری CTRL | هنگ یا ری‌استارت مکرر ESP32 → ریست؛ قطع ضربان SAFE |
| ۳ | پردازنده‌ی PWR | قطع ارتباط AgriBus → حالت امن نرم‌افزاری |
| ۴ | منطق سخت‌افزاری PWR (گیت‌ها + DIP) | قطع خط SAFE یا خرابی پردازنده‌ی PWR → حالت امن سخت‌افزاری، کمتر از ۱ ثانیه |
| ۵ | ترموستات سخت‌افزاری پشتیبان | دمای خطر → فن‌ها روشن، هیتر خاموش، آژیر؛ **بدون هیچ پردازنده‌ای** |
| ۶ | سوییچ‌های دستی Auto/Off/On | کنترل کامل اپراتور در هر شرایطی |

**هدف:** هیچ خرابی تکی (سنسور، کابل، پردازنده، برق، اینترنت) نباید به تلفات گله، محصول یا ماهی منجر شود.

## ۱۳. موضوعات باز برای نسخه‌ی بعد

1. آیا **۴ برد** (CTRL، PWR، NODE، PROBE) مورد قبول است؟ یا باید باز هم ادغام شود (مثلاً PROBE داخل NODE)؟
2. **ابعاد CTRL** (~180 × 120 mm) برای جعبه‌های مورد نظر شما مناسب است؟
3. **ولتاژ سیم‌پیچ رله‌ها:** 24V (استاندارد صنعتی) یا 12V؟
4. **LoRa:** فقط 433MHz، یا نسخه‌ی 868MHz هم لازم است؟
5. **HMI:** DWIN (رایج در بازار ایران) یا Nextion؟ اندازه‌ی پیش‌فرض 4.3 یا 7 اینچ؟
6. **صنایع:** چیزی حذف یا اضافه شود؟ اولویت شما کدام صنایع است؟
7. **رده‌ی قیمت هدف** هر مدل (برای انتخاب نهایی قطعات)؟
