## ۲. خانواده‌ی بردها

| کد | نام | نقش | وضعیت |
|---|---|---|---|
| **MC-1** | Main Controller | مغز سیستم؛ همه‌ی ارتباطات و I/O پایه | **شماتیک و PCB rev A طراحی شد** |
| CM-4G | Cellular Module | کارت دختر مودم (A7670E/SIM7600/EC200U) + SIM + آنتن | بعدی |
| IO-R16 | Relay Expansion | 16 رله روی RS-485 Modbus (سالن‌های بزرگ مرغداری) | بعدی |
| IO-AIO | Analog Expansion | 8 ورودی 4-20mA/0-10V/PT100 + 4 خروجی 0-10V | بعدی |
| WQ-4 | Water Quality | 4 کانال ایزوله pH/ORP/EC/DO برای آبزی‌پروری و هیدروپونیک | بعدی |
| LC-4 | Load Cell | 4 کانال لودسل 24 بیت (ترازو پرنده، سیلو، دام) | بعدی |
| MD-4 | Motor Driver | 4 درایور موتور DC با فیدبک جریان/لیمیت (پنجره، پرده، اینلت) | بعدی |
| AC-8 | 24VAC Valve | 8 خروجی تریاک برای شیرهای آبیاری استاندارد | بعدی |
| SN-1 | Wireless Sensor Node | نود LoRa کم‌مصرف با پنل خورشیدی، SDI-12/RS-485/آنالوگ، شیر لچینگ | بعدی |

همه‌ی ماژول‌های توسعه روی **RS-485 A** با پروتکل **Modbus RTU** کار می‌کنند و تغذیه‌ی 24V را از همان
کابل می‌گیرند (کابل 4 رشته: +24V، A، B، GND). آدرس هر ماژول با DIP-switch تنظیم می‌شود.

## ۳. تصمیم‌های کلیدی طراحی MC-1 و دلیل آن‌ها

| موضوع | انتخاب | دلیل |
|---|---|---|
| پردازنده | **ESP32-S3-WROOM-1-N16R2** | Wi-Fi + BLE داخلی، USB بومی (بدون مبدل USB-Serial)، 16MB فلش برای OTA دوبانکی، PSRAM؛ نسخه‌ی R2 (Quad PSRAM) پایه‌های IO35..37 را آزاد نگه می‌دارد؛ در ایران در دسترس |
| اترنت | W5500 (SPI) + جک HR911105A | پشته‌ی TCP/IP سخت‌افزاری، رایج و ارزان |
| LoRa | ماژول Ai-Thinker **Ra-02** (SX1278, 433 MHz) | باند مجاز 433 در ایران، رایج، آنتن IPEX |
| سلولار | **اسلات کارت دختر** 2×8 | طراحی RF مودم از برد اصلی جدا شود؛ امکان انتخاب 2G (SIM800) یا 4G (A7670E/EC200U) بسته به منطقه |
| تغذیه ورودی | 9-32V DC، دو ورودی (اصلی + باتری) با diode-OR | سازگار با تابلوهای 24V و باتری 12/24V؛ دیود OR حفاظت معکوس هم هست |
| رگولاتور 5V | **TPS54360** (ورودی تا 60V، 3.5A) | تحمل سرج 24V صنعتی (TVS در 53V کلمپ می‌کند) |
| رگولاتور 3.3V | TPS563200 (3A سنکرون) | پیک جریان Wi-Fi + W5500 + LoRa + SD |
| گسترش پایه | 2× **PCA9555** روی I²C | همه‌ی 16 پایه دوطرفه (برخلاف MCP23017 جدید که GPA7/GPB7 فقط خروجی‌اند) |
| رله | Songle/Sanyou SRD-05VDC با ULN2803 | فراوان‌ترین رله‌ی بازار؛ LED روی هر کویل |
| ورودی دیجیتال | TLP290-4 (اپتوکوپلر AC) | پشتیبانی سینک/سورس و حتی 24VAC بدون تغییر سیم‌کشی |
| ورودی آنالوگ | ADS1115 16 بیت + جامپر 4-20mA / 0-10V | یک مدار برای هر دو استاندارد صنعتی؛ PTC و TVS روی هر کانال |
| خروجی آنالوگ | MCP4728 + OPA2196 (36V) | خروجی 0-10V واقعی برای اینورتر و دیمر |
| خروجی MOSFET | IRLR2905 + بافر 74AHCT1G125 (درایو گیت 5V) | PWM تا 2A برای شیر برقی، دوزینگ پمپ، LED |
| RS-485 میدانی | ADM2587E (ایزوله‌ی 2.5kV با تغذیه‌ی ایزوله‌ی داخلی) | کابل‌های طولانی مزرعه، اختلاف پتانسیل زمین و صاعقه |
| Watchdog | TPL5010 خارجی (قابل غیرفعال با Solder Jumper) | ریست حتی در صورت قفل‌شدن کامل نرم‌افزار |
| ساعت | DS3231M + باتری CR2032 | زمان‌بندی دقیق بعد از قطع برق و بدون اینترنت |
| امنیت | ATECC608B | نگهداری کلید TLS/گواهی دستگاه |

## ۴. استراتژی PCB (MC-1)

- **4 لایه**: F.Cu سیگنال · In1 = GND · In2 = +3V3 · B.Cu سیگنال
- **ناحیه‌ی ولتاژ بالا** (رله‌ها و ترمینال‌های کنتاکت، لبه‌ی بالا) بدون صفحه‌ی مسی داخلی و با
  نوار ایزولاسیون 4 میلی‌متر تا بخش ولتاژ پایین؛ عرض ترک‌های کنتاکت 2.5mm با فاصله‌ی 2.5mm
- **ناحیه‌ی ایزوله RS-485 B** با زمین جداگانه GND_ISO و شکاف 3 میلی‌متری مس
- **آنتن ESP32** روی لبه‌ی برد با Keep-out در همه‌ی لایه‌ها
- **ترمینال‌های پلاگین Phoenix MSTB 5.08mm** (قابل جداشدن برای تعمیر سریع در محل)
- ترتیب لبه‌ها: بالا = خروجی رله‌ها؛ چپ = تغذیه و RS-485؛ پایین = I/O میدانی؛ راست = اترنت، USB، I²C، 1-Wire
